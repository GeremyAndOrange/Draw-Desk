# 产品说明

说明句: 描述 DrawDesk 的定位, 核心理念, 功能范围与后续方向.

---

## 1. 项目背景

办公时经常同时打开大量窗口: 多个代码项目, 浏览器, 聊天工具, 文档与终端, 可能还有多个显示器.

常见问题:

- Windows 虚拟桌面切换成本高, 容易迷失窗口
- 任务栏与 Alt+Tab 窗口太多, 找不到目标
- 分屏工具主要解决窗口摆放, 不解决工作场景切换
- 内网与离线环境需要完全本地的效率工具

DrawDesk 的目标是像办公桌抽屉一样管理工作窗口: 不同任务场景各占一个抽屉, 需要时整体切换.

## 2. 核心理念

1. 程序不关, 只切换场景: 所有应用保持运行, 不退出也不重开
2. 点击抽屉, 场景整体切换: 其他抽屉的窗口隐藏, 当前抽屉的窗口显示
3. 打开抽屉时恢复布局: 记录并恢复窗口的位置, 大小与最大化状态
4. 不依赖 Windows 虚拟桌面, 不需要手工拖拽窗口

## 3. 目标用户

- 多项目, 多窗口, 多显示器的 Windows 办公用户
- 开发者, 工程师, 科研人员与数据分析人员
- 内网, 离线或对数据隐私有要求的办公环境

## 4. 核心概念

| 概念 | 说明 |
|---|---|
| 抽屉 | 一组窗口或应用组成的工作场景 |
| 窗口规则 | 由进程名, 进程号, 窗口标题或正则匹配一组窗口 |
| 活动抽屉 | 当前正在显示窗口的抽屉 |
| 隐藏 | 窗口仍在运行, 但不出现在屏幕, 任务栏与 Alt+Tab |
| 布局快照 | 抽屉内窗口的位置, 大小与显示状态 |
| 显示全部 | 紧急恢复操作, 显示所有由 DrawDesk 管理的窗口 |

## 5. 功能范围

第一版功能:

- 主窗口管理抽屉, 窗口条目, 位置预览与搜索
- 悬浮窗快速切换抽屉
- 加入窗口, 移出窗口, 抓取桌面
- 每抽屉独立快捷键与两个全局操作快捷键
- 规则编辑: 进程名, PID, 标题字面匹配或正则匹配
- 切换时保存与恢复布局
- 托盘常驻与显示全部
- 本地 JSON 配置, 无需联网
- 便携 ZIP 与 Inno Setup 安装包
- 独立恢复脚本, 程序无法启动时恢复隐藏窗口

明确不做:

- 浏览器标签页管理
- 虚拟桌面集成与跨桌面移动
- 进程挂起, 内存回收与强制降耗
- 跨设备同步, 云服务与账号系统
- 复杂动画, 主题系统与多语言
- 非 Windows 平台

## 6. 产品原则

- 本地优先: 数据只保存在本机
- 离线可用: 不依赖互联网
- 不收集数据: 无遥测, 无上传, 无自动更新
- 稳定第一: 隐藏与恢复必须可靠
- 场景优先: 围绕工作任务而不是单个窗口设计

## 7. 后续方向

- 多显示器与不同分辨率配置
- 与 IDE, 浏览器等常用软件联动
- 按抽屉查看进程资源占用
- 使用统计与插件机制

## 8. 命名

- 英文名: DrawDesk
- 中文名: 窗口抽屉 / 抽屉式工作区
- 标语: Your windows, one drawer away.
