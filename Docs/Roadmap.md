# 实现步骤

说明句:按里程碑给出开发顺序、每个步骤的交付物与验收条件,配套 `TechStack.md` 的技术方案与 `Design.md` 的架构设计.

---

## 一. 总原则

本节说明拆分方式与推进节奏.

---

- 每一步都产出可运行的程序,不堆积半成品
- 先打通核心能力,再做界面细节;核心能力指隐藏、显示、切换与恢复
- 每个里程碑验证通过后再进入下一个
- 遇到技术不确定点,先写最小验证程序确认,再并入主程序

## 二. 里程碑

本节按 M0 至 M5 排列,工作量用 S,M,L 表示.

---

### M0 环境与骨架 S

- 目标:具备可编译、可运行、可提交的空项目
- 步骤:
  1. 安装 Qt 6.11.2:官方在线安装器,自定义安装;组件为 Qt 6.11.2 的 MinGW 13.1.0 64-bit
     与 Build Tools 下的同名 MinGW 工具链,CMake 与 Ninja;开发环境使用 VSCode;安装到
     `C:\Qt` 或任意目录, 安装后设置 `QT_ROOT`
  2. 验证工具链:检查 qmake,g++,windres,cmake 与 make 可用;建立 CMake 构建脚本, 生成器使用 MinGW Makefiles
  3. 在 `DrawDesk` 内建立目录:Src,Tests,Docs,Scripts,Installer
  4. 初始化 Git 仓库与 .gitignore,排除构建产物与本地数据
  5. 实现日志与配置读写的最小代码,程序能启动并写日志
- 验收:使用 MinGW 工具链可编译并运行示例窗口;程序可启动与退出;日志与配置文件生成正确;代码提交入库

### M1 平台层原型 M

- 目标:用最简方式验证全部关键 Win32 能力
- 步骤:
  1. 枚举顶层窗口,输出进程名与标题
  2. 对指定窗口执行隐藏与显示,并查询状态
  3. 注册全局热键并响应
  4. 创建托盘图标与菜单
  5. 实现单实例互斥
  6. 外观原型:用 QML 实现工具条与抽屉切换动画的最简版本,提交用户确认界面风格
- 验收:命令行或最简界面即可完成上述全部操作;隐藏后的窗口在任务栏与 Alt+Tab 不可见;外观原型得到用户确认或调整意见

### M2 抽屉核心 M

- 目标:抽屉模型与切换闭环
- 步骤:
  1. 定义配置模型与读写
  2. 实现添加当前窗口到抽屉,从抽屉移除窗口
  3. 实现切换:隐藏当前抽屉,显示目标抽屉
  4. 实现恢复全部窗口,含热键与托盘入口
- 验收:两个以上抽屉来回切换,窗口显示状态正确;恢复全部始终可用

### M3 布局快照 M

- 目标:切换时自动保存与恢复布局
- 步骤:
  1. 定义布局记录结构与序列化
  2. 切换前保存,切换后恢复
  3. 处理最大化与最小化状态
  4. 处理显示器缺失与分辨率变化
- 验收:反复切换 20 次,窗口位置与状态保持一致;拔掉显示器后窗口仍在可见区域

### M4 工具条与交互 L

- 目标:达到可日常使用的界面
- 步骤:
  1. 主窗口:抽屉列表, 窗口清单, 位置预览, 添加, 移出与抓取桌面
  2. 悬浮窗:快速切换抽屉, 拖动并记忆位置
  3. 抽屉管理:添加, 重命名, 删除与排序
  4. 规则编辑支持字面或正则标题, 同一窗口可同时属于多个抽屉
  5. 搜索集成在主窗口, 结果可直接加入当前抽屉, 包含已隐藏窗口
  6. 每个抽屉配置独立的切换键位, 前缀固定为 Ctrl+Alt
  7. 主窗口左侧提供显示全部按钮, 一键恢复所有被隐藏窗口
- 验收:不打开配置文件即可完成全部日常操作

### M5 打包发布 S

- 目标:可交付的安装包, 体积控制在 100 MB 以内
- 步骤:
  1. 发布配置:Release 构建, 使用 `Scripts/Deploy.ps1` 收集 Qt 依赖与插件
  2. 体积裁剪:只复制程序实际使用的 QML 模块, 去掉 QtTest 等未使用模块
  3. 合规:安装包附带 Qt 许可文本与声明, 核对模块许可类型, 细则见 `TechStack.md` 的 Qt 许可与商用合规一节
  4. Inno Setup 脚本:安装, 升级与卸载
  5. 安装包附带 `RestoreAll.ps1` 紧急恢复脚本, 并验证脚本可恢复隐藏窗口
  6. 一键打包脚本与 Inno Setup 安装脚本, 同时产出便携 ZIP 与安装包
  7. 附带 MIT, Qt 与 MinGW 许可文本
  8. 在干净的 Windows 10 与 Windows 11 环境测试安装与运行
- 验收:安装包可正常安装, 运行与卸载, 无残留进程, 许可文件齐全
- 2026-09-13:0.1.1 补丁版本已生成便携 ZIP 与 Inno Setup 安装包
